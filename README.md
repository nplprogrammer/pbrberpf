## pbrberpf

### Description

eZee Technosys (now under Yanolja Cloud Solution) provides an online booking engine along with their services to allow guest search. However, in its customizability, it lacks "pre-filtered" searches.

This plugin is an attempt to provide a kind of pre-filtered search for those cenarios where search results need to exclude some arbitray set of the inventory, dependent on some "conversion path."

As it is based off of current booking engine behavior, and not on any official dYCS documentation or API, caution is recommended and it should be monitored in case of a YCS update.
